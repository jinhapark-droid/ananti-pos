어반사이드 POS 재고 조정 가이드 📦

최종 업데이트: 2026-11-16 · 기능: 실사 보정, 불량 분리, 반품 처리, 분실 처리

🎯 재고 조정이란?

판매, 입고 외에 발생하는 재고 변화를 기록합니다:

  • 실사 보정 (Adjust): 실제 현장 재고와 시스템 수량이 맞지 않을 때
  • 불량 분리 (Defect): 불량 상품을 발견하고 분리했을 때
  • 본사 반송 (Return): 본사로 반품 처리할 상품
  • 정상 복구 (Restock): 반품 처리 후 정상 복구
  • 분실 처리 (Lost): 분실, 손상 등으로 더 이상 판매 불가
💡 중요: 모든 조정은 본사에 즉시 알려집니다. 조정 내용이 본사로 전송되어 기록으로 남겨집니다.

🔧 재고 조정 사용 방법

Step 1: 재고 현황 화면 열기

메뉴: 하단 네비게이션 → 재고 현황

현재 매장의 모든 상품 재고 목록이 표시됩니다.

Step 2: 조정할 상품 찾기

검색: 화면 상단 검색창에 상품명, 컬러, 코드 입력

  • 예: "에일러론 블랙" → 해당 상품만 필터
  • 예: "S04188" → 이지어드민 코드로 검색

Step 3: "조정" 버튼 클릭

테이블: 각 상품 행의 맨 끝 → 조정 버튼

Step 4: 재고 조정 모달 채우기

📋 조정 모달 항목:

항목 설명 예시
현재 재고 시스템에 기록된 현재 수량 (읽기만) 2개
처리 방법 조정 사유 선택 실사 보정, 불량 분리, 본사 반송 등
조정 방향 감소 (-) 또는 증가 (+) 실사 후 더 많으면 증가 선택
조정 수량 증가/감소시킬 개수 3
조정 후 (미리보기) 조정 후 최종 재고 (자동 계산) 2 → 5개
메모 선택: 조정 사유 상세 기록 "실사 결과 재고 초과 발견"

✅ 실제 사용 예시

예시 1: 실사 보정 (재고가 더 많음)

상황: 에일러론 블랙 S 실제 재고 5개인데 시스템엔 2개

  • 현재 재고: 2개
  • 처리 방법: 실사 보정 선택
  • 조정 방향: 증가 (+) 클릭
  • 조정 수량: 3 입력
  • 결과: 2개 → 5개 (미리보기에 표시)
  • 메모: "11/16 실사 결과 재고 초과" (필수 아님)
  • 저장 클릭 → ✅ 완료

예시 2: 불량 분리 (5개 중 2개 불량 발견)

상황: 에일러론 블랙 M 5개 중 불량 2개 발견

  • 현재 재고: 5개
  • 처리 방법: 불량 분리 선택
  • 조정 방향: 감소 (-) 클릭
  • 조정 수량: 2 입력
  • 결과: 5개 → 3개 (미리보기에 표시)
  • 메모: "지퍼 불량 2개 발견, 본사 보험 처리 예정"
  • 저장 클릭 → ✅ 완료

⚡ 핵심 기능

🎨 조정 후 미리보기

수량을 입력하면 실시간으로 조정 후 최종 재고가 표시됩니다.

  • 현재 재고: 2개
  • 조정 후: 2개 → 5개 (증가 선택, 수량 3)

✅ 현재고 즉시 반영

조정 저장 → 현재 매장 재고 KPI가 즉시 업데이트됩니다.

  • 이전: 281개 SKU
  • 조정 후: 284개 SKU (+3개)

  • ❌ 한 번 저장된 조정은 수정 불가 (다시 조정하려면 반대 방향으로 조정)
